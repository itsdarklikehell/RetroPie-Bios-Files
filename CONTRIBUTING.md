# Contributing to RetroPie-Bios-Files

Bedankt voor je interesse om bij te dragen!

## Hoe bij te dragen

1. **Fork** de repository
2. **Creëer** een nieuwe branch (`git checkout -b feature/my-feature`)
3. **Voeg** je wijzigingen toe
4. **Commit** met duidelijke commit messages
5. **Push** naar je fork
6. **Open** een Pull Request

## Richtlijnen

- Voeg alleen BIOS-bestanden toe die legaal gedistribueerd mogen worden
- Voeg de MD5-hash toe van elk BIOS-bestand
- Documenteer de bron van elk BIOS-bestand
- Test het downloadscript na wijzigingen
