# Security Policy

## Reporting a Vulnerability

Als je een veiligheidslek vindt, maak dan geen public issue aan.
Contacteer de onderhouder rechtstreeks met details over het lek.

## Scope

Dit project bevat BIOS-bestanden en download-scripts voor RetroPie.
Veiligheidsproblemen in de download-scripts zijn in scope.

## Disclaimer

Dit project is bedoeld voor legitieme emulatie-doeleinden.
Gebruik alleen BIOS-bestanden waar je de rechten op hebt.
